DOCX formatting, made repeatable

论文排版，不该靠一次次手工调整。

一款 macOS 原生工具，把页面、正文、标题、公式、表格和题注等格式要求保存成可复用的规则。

查看源代码查看功能

从文档结构出发，而不是逐段修补。

Paper Formatter 读取 DOCX 的实际结构，识别不同对象后按规则处理，让同一套版式可复用、可检查、可迭代。

结构化识别

识别 1–6 级标题、Office Math 公式、表格、图表题、参考文献、图片、代码块和列表。

规则可保存

把字体、字号、行距、缩进、对齐和页面边距放进 JSON 配置，减少重复设置。

保护原文件

默认输出为 formatted 副本；覆盖原文档必须经过清晰的二次确认。

公式有专门处理

独立公式与行内公式分别处理，支持居中公式与右侧编号的常见论文排版需求。

原生工作台

SwiftUI 负责文件选择、规则编辑和状态展示；无需在多个脚本之间来回切换。

保留已有内容

在可处理的范围内保留图片、表格、页眉、脚注、尾注和批注等文档部件。

把“这篇论文怎么排”变成一份配置。

规则和界面分开：在同一套规则结构上扩展页码、题注编号和期刊模板，不需要推倒已有工作流。
